# Atlas web client (the whole app)

Mode: Operate. Users: a mixed project team (PMs, quantity surveyors, engineers) and non-technical reviewers watching a shared laptop screen in a meeting room, daytime office light. Job: load a folder, ask a question, trust the answer at a glance, check it in one click, export the rows. Constraints: Mantine 9.7 theme object owns every colour, spacing and radius; one brand hue plus neutrals; colour only for warnings and errors; no hex in components; English or Arabic interface (Arabic fully right to left); light and dark themes, light by default; Arabic answers right to left.

## Direction contract

THESIS: The category standard, chat-with-your-documents, executed at the craft of Claude.ai (calm conversation column, the question box under the heading on a fresh chat), Perplexity (numbered sources you can open) and Linear (crisp, dense, quiet chrome; the content on an inset sheet). It refuses the demo look: gradients, glowing AI sparkles, bubble chat, cards inside cards.

OWN-WORLD: The top bar and sidebar are one continuous cool-neutral chrome field; the conversation sits on it as an inset sheet (page ground, 1px hairline, 8px corners; edge to edge on a phone). One brand hue, a deep ink blue (Mantine custom 10-shade palette, primaryShade 7 light / 6 dark), spent only on the primary action, focus rings, selection, links, the cited-text highlight, the open file in the tree, the streaming caret, and the ring of the call avatar while Atlas speaks. Dark theme: the same roles on blue-black slate (chrome darkest, page a step up, raised surfaces a step above), the gray, ink, amber and red shades remapped as roles so every component reads in both; the rendered PDF page stays white paper. Neutral badges for document type and ok status; yellow only for scanned and too-large, red only for corrupt and encrypted, gray for empty and skipped. System UI font stack (Segoe UI carries Arabic on Windows), one family, tabular Western numerals in both languages, ui-monospace only for SQL and tool input. Type scale about 1.15: 12, 13, 15 body, 17, 20, 26. Radii 4/6/8. Hairlines instead of shadows; a soft offset shadow only on modals and menus. The mark is a folded map of three panels, neutral ink beside the wordmark. The call avatar is a philosopher's bust in graphite line work on white, like marble, in both themes.

STORY: The reviewer sees the project folder as a tree, which files Atlas read and which it could not, and opens any file in the viewer from it. They ask in plain words, in English or Arabic, from the box under the folder's name or a suggested question in their interface language; watch the answer stream; see the exact rows and numbered sources; open a source at its page or rows; expand "How I found this"; export the table. Or they press the phone and ask out loud. They switch language or theme from the top bar and the whole interface follows, mirrored for Arabic.

FIRST VIEWPORT: 52px chrome top bar: folded-map mark and "Atlas" at the start; at the end, the last answer's cost and time, the model picker, Clear chat, a hairline, then the language switch (the other language named in its own script) and the light/dark toggle (both move to the sidebar foot on a phone). 300px chrome sidebar: folder path field with a folder icon and Load, a compact dropzone, an indexing line while loading, then "Documents" over a folder tree: the loaded folder as a collapsible root with its file count, real subfolders nested, files on a hairline rail under each folder's chevron (kind icon, name, problem badge; pages or sheets and document type under it; the whole row opens the file in the viewer), and "N files skipped" at the foot. Main: the inset sheet holding a centred 760px column. With nothing asked yet, a block a little above the middle: the heading "Ask about <folder>", one summary line, the question box, then five suggested questions as full-width quiet rows. Once asked, the question box docks at the bottom of the sheet and each turn is the question as a heading-weight line, the streaming answer, the result table, numbered source rows, "Said aloud" under a spoken answer, and a collapsed "How I found this". During a call the call card takes the question box's place.

FORM: Category standard (canon), chosen by the user over the rolled direction; seed key 7725660b. Refined on 2026-10-29 at the owner's request (keep the look, finish it higher): dark theme, Arabic interface, folder tree, inset sheet, question box under the heading. Quality bar: Claude.ai, Perplexity, Linear.

Signature interaction: the answer streams in with a brand-blue caret, then the sources and table settle in below with one 180ms fade-and-rise; clicking a numbered source opens the viewer at that page with the quoted text highlighted, or at the sheet scrolled to the cited rows with those rows tinted. In a call, the bust's mouth moves with Atlas's measured voice while its ring holds the caret's ink.

Motion grammar: 150 to 200ms ease-out on state changes only (collapse, folder open and close, fade-in of finished parts, hover). Skeleton rows while tables and the tree load. No page-load choreography. One exception, approved by the user on 2026-10-29: inside the call avatar, and only while a call is open, gentle continuous motion; a still pose per state under reduced motion, and no motion in a hidden tab.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
