# Note

**Which agent.** Claude Code, first on Claude Opus 5.5 and later on Fable 5.1. I did not hand it the brief and wait. I decided what Atlas would be, how the code would be layered and which rules every answer must obey, and wrote them down before any code existed. Claude Code wrote the code to those contracts, in about fifty small units, in parallel, while I steered: what to build next, what to fix, what to throw out.

**How long.** About 20 hours across 28 to 30 October 2026: one on the contracts and design, three on the parallel build, one on checking and fixing answers, the rest on voice, the Arabic interface, free providers and docs.

**Decisions I would defend.** The biggest: the model never types a number. Every table becomes a real database table, so totals and "above SAR 1 million" questions are computed over every row, and a guard rejects any figure the code did not produce. Each answer arrives in one fixed shape with its sources attached, and when no source checks out it says "not found in the loaded documents" rather than guessing. Search looks for exact words and for meaning at once, and scanned pages are read as images. Atlas runs on whichever model is at hand: OpenAI by default, with its small model keeping the demo cheap, Google's free tier, or a model on the computer itself. Voice calls hand each question to the same agent, so a spoken total passes the same checks as a typed one. Underneath, the code sits in clear layers wired together in one place, and 1,919 unit tests run with no API key and no network.

**Given more time.** I would mark each claim in an answer with its source, read scanned pages more cheaply, handle more PDF table layouts, cap the spend per question, make very large folders faster to search, test the free models as thoroughly as the paid one, and leave a tidier history than hundreds of tiny commits.
